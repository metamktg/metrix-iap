# Metrix IAP Dashboard UI/UX + CSS Spec Sheet

## 1. Core Visual Direction

**Design language:**
Premium dark-mode performance cockpit for ad intelligence.

**Brand attributes to express:**

| Attribute          | UI Translation                                                 |
| ------------------ | -------------------------------------------------------------- |
| Precision          | Thin borders, tight spacing rhythm, sharp hierarchy            |
| Intelligence       | Blue/cyan glow, data-dense cards, AI-recommendation modules    |
| Clarity            | High contrast text, clean card grouping, restrained motion     |
| Performance        | Live signals, status indicators, trend deltas, compact metrics |
| Proprietary Engine | Infinity-loop visuals, system status, “Sprint Test” CTA        |

The interface should feel closer to:

* **Hyros / Triple Whale / Motion / Madgicx**
* High-end trading terminal
* AI command center
* Performance-marketing analytics cockpit

Avoid:

* Flat generic SaaS cards
* Bright white backgrounds
* Corporate dashboard clichés
* Oversized empty spacing
* Rounded toy-like components
* Heavy gradients that reduce readability
