## Claude Code reference rule

When implementing a Metrix interaction, open the exact Watermelon full-page reference URL supplied for that interaction first. Reproduce the interaction model, state transitions, spatial behavior, timing character, and affordance quality — not Watermelon branding. Translate it into the existing Metrix design system and data model. Do not introduce motion where it reduces scanability, delays access to data, moves a user’s reading target, or turns an analytical interface into a showcase. Respect prefers-reduced-motion, keyboard/focus behavior, responsive layouts, and existing application state.
