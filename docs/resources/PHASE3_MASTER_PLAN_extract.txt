METRIX IAP · PHASE 3 · CLAUDE CODE EXECUTION PLAN
Command Deck
Makeover master plan

Full CSS, shell, component, and data-surface overhaul for the Metrix IAP — hybrid of the v2.0 electric-blue cockpit and Nocturne's tonal-ramp discipline, built strictly on top of UI/UX Pass Phases 1–5 and the surgical repair pass.

Progressive-disclosure order is fixed for every module this plan describes: decision (the number/verdict) → evidence (what supports it) → explanation (methodology, source, identifiers). This document itself follows that order top to bottom — invariants and tokens before shell mechanics, shell before epics, epics before the field-level coverage audit.

Why this won't look like the rest
KILL

Gauge dials · rainbow multi-hue KPI grids · glossy tilted-mockup framing · generic "top products" donuts · neumorphic drop shadows. The genre default everyone converges on — Madgicx, Hyros, generic GoHighLevel-style templates — is the same navy-neon dashboard with mismatched accent colors bolted onto every card.

KEEP — THE ACTUAL BETS

The Loop Spine as navigation, not a menu · the MST 4×4 matrix as a hero object nobody else has · evidence chips tracing every claim to source cells · honesty states as a designed language instead of a screen that ships empty.

The edge isn't prettier gauges. It's that every number on screen has a receipt.

00
Binding invariants

Validate these before and after every epic. They're established, tested behavior from Phases 1–5 and the repair pass — a Phase 3 change that breaks one is a regression, not a redesign.

I1
Honesty pattern

UI never fabricates. Null seed fields render honest pending states; signal-card structured fields render only when producer-supplied, never derived from prose.

I2
Cohort-awareness

No ROAS / purchase-funnel hardcoding. Terminal metrics come from cohort configuration (ecommerce · lead_gen · service · app).

I3
Locked IA

navTree.ts is the single source of truth. Shell geometry may change; the 10 sections, routes, badge keys and dataSource annotations do not.

I4
Disclosure rulebook

No sentences on the first layer. Typography roles from typography.ts only. Ratcheting gate: per-file violation counts may only go down.

I5
A11y floor (Phase 4)

Focus traps on dialogs, reduced-motion respected, keyboard rows in virtual tables, aria-labels on icon-only controls, focus-visible rings everywhere.

I6
Execute-on-command

The IAP loop never auto-runs. Ingestion refreshes data; the UI only recommends the next runnable stage.

I7
Test suite is a contract

704 + 209 + 55 tests green at every epic boundary. Existing data-testids (e.g. row-audience-segment-*) are kept.

01
Hybrid v3 token system
KEEP — METRIX V2.0 IDENTITY

Deep-navy grounds (#020711 / #050b18) · electric blue #155dff primary · cyan #16d9ff intelligence accent · filled-blue primary CTA · 7-level surface scale · high density · dark-only.

ADOPT — NOCTURNE DISCIPLINE

OKLCH 100–900 tonal ramps per role, replacing alpha-tint literals · accent as line and glow, never flood · rules fade to transparent at their ends · outlined secondaries · 2px accent focus-visible everywhere.

2Icon Rail + Context Column

56px rail = the 10 locked sections, numbered and badged. Selecting opens a 200px column of that section's children + command-center landing. Mobile keeps the overlay pattern.

The IAP loop (Data → Analysis → Strategy → Briefs → Report → Re-run) as a persistent stage row on account scope, statuses from loop_status; full LoopCommandChain stays on command-center pages.

Right rail (46 → 320px) merging the Task Tray with a live Listen feed ranked by normalized priority; null priority renders the raw impact string, never a substituted bucket.

Navigate sections and accounts, trigger only actions that already have a button today — never a new auto-run path.

The category-differentiating bets are the loop spine, matrix-as-hero MST, unified scope bar, evidence-linked strategy, and the honesty system rendered as a first-class visual language.
