01 — Brand Identity

Concept

Dark Command-Center Cockpit. Metrix is a performance intelligence platform for media buyers and performance marketers. The UI is designed to feel like mission-control software — authoritative, precise, and data-dense — not a typical SaaS dashboard.


Deep navy blacks, electric blue intelligence highlights, and a restrained use of color signal data hierarchy. Every surface earns its place; decoration is functional or absent.

Personality

VoiceDirect, expert, confident. No fluff.
Visual tonePrecision instrument, not consumer app.
DensityHigh — data-dense layouts, tight spacing.
MotionPurposeful only — 140–220ms, ease-out.
AudienceMedia buyers, performance marketers, growth leads.
Tagline"Performance intelligence for marketers who need to move faster."
ℹ The app is always dark-mode only. There is no light mode variant. All CSS tokens are defined once in :root with no .dark override needed. The .dark class block in index.css mirrors the root values as a Tailwind compatibility shim.
